# Manhattan Coffee House

Uma página web de apresentação para a Manhattan Coffee House, com informações sobre a cafeteria, seus cafés, localização e horários de funcionamento. O projeto demonstra a criação de uma página estática com HTML e CSS e um visual inspirado em cafeterias.

![Imagem de destaque do projeto](img/parallax-imagem1.png)

## Sobre o projeto

A página reúne o conteúdo em uma única tela, com navegação no topo para acessar as seções de informações, contatos e horários. Imagens de fundo com efeito parallax ajudam a separar os blocos de conteúdo e compõem a identidade visual do site.

## Funcionalidades

- Navegação entre seções por links internos.
- Apresentação da cafeteria e de seus cafés.
- Imagens de fundo com efeito parallax.
- Seção de contato com mapa incorporado.
- Lista de horários de funcionamento.
- Layout estilizado com fontes do Google Fonts.

## Tecnologias

- HTML5
- CSS3
- Google Fonts
- Google Maps Embed

## Como visualizar

Não é necessário instalar dependências ou executar um servidor:

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.

Para desenvolver com recarregamento automático, abra a pasta do projeto no VS Code e use uma extensão de servidor local, como o Live Server.

## Estrutura do projeto

```text
.
├── index.html       # Estrutura e conteúdo da página
├── Cafeteria.css    # Estilos e efeitos visuais
└── img/             # Logotipo e imagens usadas na página
```

## Personalização

Os textos, horários e dados de contato são conteúdo de demonstração e podem ser editados em `index.html`. As cores, imagens de fundo, dimensões e demais estilos podem ser ajustados em `Cafeteria.css`; os arquivos de imagem utilizados estão na pasta `img/`.
